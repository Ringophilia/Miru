# 实现进度

开始日期：2026-10-22。当前交付目标是规范第 15 节的 M0，完整产品还需 M1–M4；iOS 按规范在 Android M4 后开始。

## 已实现的 M0 代码

- 原生 Android 多模块工程，包名 / minSdk / 设计 token 与规范对应。
- GeckoView 与稳定版 Android Components；单个共享运行时，BrowserStore 为唯一标签状态源。
- Compose 地址栏、原生新标签页、可持久化编辑 / 添加 / 移除 / 撤销的快捷方式、普通 / 无痕标签组、两列标签切换器、关闭 / 撤销与主菜单。
- 地址或搜索输入判断、已打开标签匹配、输入全选、网页加载进度与网站连接状态。
- 基于 SessionStorage 保存普通标签及 Gecko 导航栈；无痕标签排除在持久化之外，启用 FLAG_SECURE。
- 前进 / 后退 / 刷新 / 停止、页内查找、桌面站点开关、分享、默认浏览器请求、外部网页 / 文字分享 / 搜索 Intent。
- 标签缩略图仅在内存中保留，最多 12 张，宽度不超过 360 px；无痕页面不截取缩略图。
- DataStore 设置即时生效：搜索引擎、深浅色 / 系统主题、动态取色、地址栏上下位置；中文 / 英文资源。
- 标准自适应与主题应用图标、SVG 源文件、关于与 Mozilla 许可信息。
- 历史记录（B7）：Gecko `HistoryTrackingDelegate` 记录普通标签访问（无痕会话 Gecko 不回调，已有设备测试），按日期分组、搜索、滑动 / 菜单删除、按时间范围清除，均可撤销；地址栏建议含历史匹配。
- 书签（B8，平铺列表）：菜单星标切换并可撤销 / 编辑，书签页搜索、编辑、删除、在新 / 无痕标签打开；地址栏建议含书签匹配。

### 与规范的偏差：历史与书签存储

规范 5.10 写明使用 AC `browser-storage-sync`（Places）。实测解析 158.0.2 依赖树会新增 Glean 遥测 SDK、sync15 / syncmanager / tabs、relay、viaduct 与 WorkManager，且 `glean-native` 解析失败，与第 12.1 节「无遥测、无同步」冲突。因此改为 `:core:data` 的本地 SQLite（`BrowsingLibrary`，无新依赖，排除云备份）。接口集中在 `BrowsingLibrary.History` / `Bookmarks`，日后换 Places 只需替换实现。书签文件夹（P1）未做。

### UI 修正（2026-10-22）

- 状态栏 / 导航栏图标随应用主题与无痕状态切换（此前强制深色主题或无痕时为深色图标压深色背景）；新增夜间窗口背景，冷启动不再闪白。
- 编辑地址、进入设置 / 历史 / 书签时 GeckoView 保持挂载（全屏页改为叠层 + 共享轴 X 过渡），不再销毁重建。
- 加载进度条改为叠在工具栏边缘，不再引起网页高度变化；进度用 spring 追赶，100% 停留 150 ms 后淡出。
- 全局单一 Snackbar，底部工具栏时浮于其上方 8 dp；带操作的 Snackbar 一律 6 秒。关闭标签提示带标题。
- 页内查找打开即聚焦弹出键盘，胶囊样式，空查询不显示计数。
- 菜单隐藏不可用图标（NTP 上整行隐藏），工具栏隐藏未接入的盾牌；快捷方式 / 列表使用按域名取色的首字母图标；标签数按钮朗读数量。
- 底部地址栏在网页表单弹出键盘时让位；地址栏建议区分「搜索」与「打开网址」，历史 / 书签条目带「↖ 填入」。

## M1 开始前

先完成规范 R2/R3 的最小验证，再集成 uBO；必须使用官方签名 XPI，记录版本 / SHA-256、保留许可证，确认本地安装与首屏扩展就绪的行为。不能用 M0 当前的 Gecko 跟踪保护冒充 uBO 广告拦截。

下载引擎需用 MockWebServer 测试 Range、ETag、断点与重试。Cookie 和授权头不写磁盘。M2 再接入独立播放器 Activity 与媒体会话服务。

构建、模拟器用例结果与限制记录在 `M0-VALIDATION.md`；未运行的验收不标记完成。
