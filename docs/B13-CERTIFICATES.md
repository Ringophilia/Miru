# B13 证书查看（2026-11-05）

## 实现

地址栏站点信息新增「查看证书」，展示浏览引擎提供的服务器 X.509 证书：网站、签发给谁、签发机构、有效期、序列号和 SHA-256 指纹。日期按设备时区显示，字段可选择复制。连接未被引擎标记为安全时，查看器显示相应提示；本功能不更改证书信任或放行 TLS 错误。

数据来自 Android Components 158 的 `SecurityInfo.certificate`，经当前页面协议、连接主机和加载状态检查后生成展示数据。新页面加载、重新加载和历史导航先清除旧安全状态；不同主机、HTTP 或尚未提供证书的页面不复用旧证书。链接中的用户名和密码不进入展示模型。

查看器只绑定当前标签和证书指纹；导航、切换标签、界面重建或关闭发起它的无痕标签后退出。新增展示数据和查看器选择仅在内存，不新增证书磁盘缓存或 Android 保存状态。
