# 按站点和路径跳过片头片尾 P20

在原生播放器的「播放选项 → 跳过片头片尾」中选择规则范围。可以仅应用到当前页面、应用到当前目录或上级目录，也可以应用到整个域名。首次设置优先建议当前目录，顶级单页则建议只应用到该页。已有规则按最具体的范围生效，目录按完整路径段匹配。规则只保存域名与路径范围的摘要以及两个时长，查询参数和片段不参与匹配。

两个时长都可加减 5 秒。「设为当前位置」会按当前播放位置设置片头的结束点或片尾的开始点。片尾时长从视频结尾倒计，设为 0 秒可关闭对应跳过。设置合计必须短于当前视频。已有规则遇到过短的视频时会跳过规则处理。该入口仅用于有普通站点来源且可拖动的点播，无痕播放不读取或保存规则。

起播时如果尚在片头区间，播放器会跳到片头末尾并提示。已过片头的续播位置保持原样。自然播放进入片尾时跳到视频结尾并提示，主动拖进片尾可继续观看。每条自动跳过在本次播放中最多一次，切换解码器重开来源也不会重复跳过。

- API 35 x86_64 SwiftShader 模拟器 `playback-skips-device-01` 通过 2/2，JUnit 30.994 秒。专项通过实际界面设置 10 秒片头，用「设为当前位置」设置 8 秒片尾，从同目录下一集重新打开并验证实际片头跳过、自然播入片尾后直接结束、主动拖进片尾仍播放。相似前缀和无痕播放均未沿用该规则。原有横竖屏和重进全屏的播放器用例也通过。
