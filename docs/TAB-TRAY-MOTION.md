# 标签切换器的卡片过渡

按 §7.3 实现打开标签切换器和从卡片进入网页。网格在打开时先让当前标签所在行可见，测量对应卡片的实际位置。当前页的预览在窗口和卡片之间变换，圆角从 0 变为 12 dp，其余卡片随背景淡入并从 0.92 倍变为正常大小。选择另一页时，从被点卡片的位置反向展开。可测量的过渡使用 350 毫秒时长。找不到可见卡片时回退到整体淡入淡出，系统减少动画时使用 150 毫秒淡入淡出。

转场复用已经存在的普通页内存缩略图和无痕占位，保留同一个 GeckoView。无痕页在切换器显示普通标签分组时仍持续使用 `FLAG_SECURE`。

## 验证

- 固定构建 `tab-tray-motion-build-01` 通过，766 项源码输入无漂移。设计模块 3 项 JVM 测试通过，标签模块无独立 JVM 用例。
- API 35 x86_64 模拟器 `tab-tray-motion-device-01` 通过 3 项。以真实 Gecko 网页验证了当前标签在较后位置时仍从正确的卡片完成展开和缩小。逐帧比较了播放中的预览矩形、实际卡片位置和全屏网页宽度；点另一张卡片后从该卡片所在侧展开并选中其网页。另一项在系统动画比例为 0 时验证没有几何变换，并确认无痕页后面的窗口仍受保护。原有普通与无痕分组用例同轮通过。
- 两个安装包均核对大小和 SHA-256，已移除临时 APK 副本和测试用户，并恢复模拟器动画设置。证据在 `artifacts/m3-cached-ranges/tab-tray-motion-*/` 与 `artifacts/tab-tray-motion/`。真机、高刷新率及动画期间多指操作仍待核对。
