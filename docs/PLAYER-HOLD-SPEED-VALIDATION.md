# 长按后滑动换倍速档 P3

播放时长按画面会先采用「设置 → 播放器」里的长按倍速。保持手指按下，向左或向右每滑 40 dp 换一档，可用 1.5、2.0、2.5、3.0 倍。滑回起点附近恢复本次长按的起始档。屏幕顶部的胶囊跟随实际请求的档位更新。松手、取消或播放器退到后台时恢复按下前的速度。长按期间不会执行进度拖动或音量、亮度调节，原生播放器仍保持音调。

诊断用例捕获到 Android 横屏切换期间两次事件的本地坐标原点变化，导致本应向左换档的事件被解释为小幅右移。长按换档改用按下与移动事件的屏幕坐标，普通单指拖动仍沿用现有坐标处理。早期固定包三轮分别为 3/4、2/4、3/4，之后的诊断轮为 1/2，原日志和失败均保留。

固定包 `player-hold-speed-build-02` 通过编译，721 项输入无漂移，播放器 JVM 94/94，Lint 0 错误和 29 警告。主 APK SHA-256 为 `86e9d0726ac8f952fbc1831e802fcdd678e14b1982cb97c26ae755ef7c6d9469`，测试 APK 为 `54ffd873539ebcb126285fbe47a7f682296cd3da67c141e7acea26e546205a00`。

API 35 x86_64 SwiftShader 模拟器的 `player-hold-speed-fixed-device-01` 和 `player-hold-speed-fixed-device-02` 各通过 4/4，JUnit 分别为 25.091 和 23.206 秒。真实触摸覆盖四档、未满一步时保持当前档、松手和取消恢复、暂停无效、音调保持、进度和亮度音量隔离。播放器单测另外覆盖 40 dp 的精确边界。两项原有双指缩放也通过。各轮在独立临时 Android 用户中预先确认沉浸模式提示，安装后核对固定包，结束后恢复原用户并移除临时用户。

命令、APK 核对和日志见 `artifacts/m3-cached-ranges/player-hold-speed-*/`。真机手感和速度响应延迟仍待测。本批未跑完整回归或重新构建 ARM64 包。
