# 盾牌拦截计数动效

按 §7.3，零次拦截时只显示灰色盾牌。出现拦截时，盾牌在 150 毫秒内变为主题的拦截色。数字变化时，旧数字上移淡出，新数字自下向上进入。减少动画时数字在原地交叉淡入淡出。刷新提示沿用错误色，数值仍取自实际 uBlock 上报。

浏览器会同时发布计数所属的标签，工具栏只接收当前标签的数值。切换标签或地址后，上一页留在动画里的数字不参与新页面的过渡。显示值超过 999 时仍简写为 `999+`，读屏取得当前完整计数。
