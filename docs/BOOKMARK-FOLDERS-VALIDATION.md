# 书签文件夹 B8

「移动设备书签」是默认文件夹。书签页内可以新建多级文件夹，移动、重命名和删除已有文件夹。删除只移除选中的文件夹，其中的书签和直属子文件夹移到上一级。默认文件夹一直可用，文件夹也不能移动到自身或自己的子文件夹中。

新星标先保存在默认文件夹，可从提示的「编辑」或书签列表的「编辑书签」选择位置。同一个网址仍只保存一条书签。搜索跨文件夹显示结果及其位置，单条书签的删除撤销会恢复原文件夹，原文件夹已经删除时则恢复到默认文件夹。

## 验证

- 固定包 `bookmark-folders-build-04` 编译通过，735 项源码输入无漂移。Lint 0 错误、29 警告。数据模块 5 项 JVM 测试通过，引擎 133 项通过、1 项因 Windows 符号链接能力跳过。书签界面模块没有独立 JVM 用例。
- API 35 x86_64 模拟器 `bookmark-folders-device-03` 通过 7 项。数据库专项用旧版表结构和真实 SQLite 文件升级，验证书签的编号、标题、网址和创建时间，以及历史访问次数。随后移动书签、关闭并重开数据库，确认位置和搜索结果留存。其他数据测试验证子文件夹移动、循环移动拦截、删除后的内容保留和单条书签撤销。
- 界面专项用本地网页实际点星标，在「编辑」里选子文件夹，通过搜索找到书签及所在位置。进入子文件夹并重建界面后，点书签可以打开网页。删除父文件夹后，仍可进入子文件夹找到书签。
- 首轮固定构建有 Kotlin 类型错误，修正后通过。早期设备测试有一次搜索输入框和结果匹配冲突，一次测试方法签名不符合 JUnit 要求。原始日志保留，修正测试后整组复测。最终安装包大小和 SHA-256 已核对，APK 临时副本已删除，模拟器恢复原用户并移除测试用户。证据位于 `artifacts/m3-cached-ranges/bookmark-folders-*/` 和 `artifacts/bookmark-folders/`。

本批沿用本地 SQLite，Places 偏差仍待验收决定。真机、完整回归和 ARM64 验证留到后续检查点。
