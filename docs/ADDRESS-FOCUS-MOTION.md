# 地址栏聚焦和建议动效

本批实现 §7.3 的新标签页搜索框、网页地址栏聚焦和建议行进入。新标签页搜索框从原位置和尺寸移动到工具栏，Logo 和快捷方式上移 16 dp 并淡出。网页地址栏展开时，标签和菜单淡出并缩到 0.8，左侧图标渐变为返回箭头。聚焦的时长使用 300 ms token，真实输入框全程可编辑。

建议行从下方 8 dp 淡入，前六个位置按 20 ms 间隔排列，后面的行沿用最后一个延迟。当前输入的首行保留自己的位置，同一个建议的动画状态也会随列表更新保留。系统动画比例设为 0 时，输入框直接使用目标位置，建议行直接使用列表位置，颜色和透明度仍可短暂过渡。App 在运行时接收该设置的变化。

## 验证

- 固定构建 `address-focus-build-02` 编译通过，744 项源码输入无漂移，Lint 0 错误、29 警告。设计模块 3 项 JVM、通用模块 18 项 JVM 通过。工具栏和新标签页模块的 JVM 任务无独立用例。
- API 35 x86_64 模拟器 `address-focus-device-02` 通过 6 项。两项新增测试逐帧检查新标签页输入框的中途和最终位置、途中输入、网页地址栏展开，以及运行中关闭系统动画后的固定位置。原有在线建议、填入、内联补全、无痕限制、旧响应清理和设置页路由也复测通过。首轮有一项在测试时钟冻结时过早读取输入，修正后重跑，原结果保留。
- 安装的主包和测试包均核对大小及 SHA-256。恢复了系统原有动画设置和模拟器原用户，移除了测试用户与临时 APK 副本。结果在 `artifacts/m3-cached-ranges/address-focus-*/`，JVM 报告在 `artifacts/address-focus/`。

建议行的间隔使用代码中的时长参数。逐项画面时序、底部工具栏实际位置、60/90/120 Hz 真机表现和整套减少动画流程仍待验证。
