# 横滑关闭标签卡片

按 §5.5、§7.2 和 §7.3，手势位置从静止的网格位置读取，卡片画面单独跟手平移。透明度随距离下降，移动一张卡片宽度时完全淡出。释放时位移超过卡片宽度的 40%，或速度超过 1,000 dp/s，会在对应方向关闭。其余情况回到原位。滑出与回弹沿用松手速度，网格补位使用项目弹簧参数。减少动画时去掉平移，保留淡出，剩余卡片直接补位。

关闭按钮和横滑最终使用同一个关闭入口，延迟动画期间出现新操作时可以中断，同一次关闭只提交一次。撤销沿用 Gecko 和浏览器的会话恢复。

## 验证

- 固定构建 `tab-card-dismiss-build-02` 通过，770 项源码输入无漂移。标签模块 2 项 JVM 测试覆盖距离和速度的阈值与方向，设计模块 3 项 JVM 测试通过。
- API 35 x86_64 模拟器 `tab-card-dismiss-device-02` 通过 3 项。实际 Gecko 卡片的位移和图像颜色验证了按住时跟手和平滑变淡，慢速短滑回原位、过线关闭、短距离快速滑动关闭、相邻卡片补位均通过。通过提示撤销后，实际从恢复 tab 的当前页返回上一页。前一轮在 Gecko 还未发布返回栈时读取了状态，等待实际历史状态后复测通过。标签切换器进出和无痕保护的两项回归同轮通过。
- APK 大小和 SHA-256 已核对，临时 APK 副本及测试用户已移除。证据在 `artifacts/m3-cached-ranges/tab-card-dismiss-*/` 与 `artifacts/tab-card-dismiss/`。真机、多指交叉输入及高刷新率手感仍待验证。
