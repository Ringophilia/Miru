## 2026-11-03 · 方向调整

**为什么调整**：10-31 以来 24 个提交里有 21 个围绕播放器进度条上的“已缓存区段”（P11，第二轮功能）或回归记录；9 天升了 15 个版本号，每次都跑全套回归和打包。同时，用户每天会碰到的基础功能还有不少没做，App 也还没在真手机上用过。

**现在能用的**：浏览网页、普通 / 无痕标签、历史和书签、内置 uBlock Origin 拦广告、断点下载、网页视频交给原生播放器（倍速、双击快进、拖动、画中画、字幕音轨）、HLS / DASH 视频离线、Anime4K / FSR 超分、网页文件上传、摄像头 / 麦克风 / 定位权限。以上主要在模拟器上验证过。

**还没做、接下来按顺序做**：

1. 无痕标签通知、首次启动设默认浏览器引导（地址栏建议、域名补全、网站图标和六个主题色已补，见下）
2. 收尾网页权限和弹窗提示；查清 uBlock 第一次安装偶尔超时的原因
3. 后台播放、双指缩放、长按后滑动换倍速、跳过片头片尾、HTTPS-only 等安全设置、书签文件夹、下载页存储条
4. 动效、设置补全、无障碍

**暂停**：缓存区段（P11）的深入工作已暂停，未完成部分保存在 `wip/p11-cache-ranges` 分支。

**需要维护者帮忙**：有空时用 USB 连一台真手机，App 才能做真机测试。

## 2026-11-03 · 地址栏建议与域名补全

**这批做了什么**：已停止缓存区段工作，未提交部分已保存在 `wip/p11-cache-ranges`，现在继续在 `main` 开发。通用磁盘清理修复单独保留在主分支。

**App 里能看到什么**：普通标签里输入搜索词后，会向当前选择的 Google、Bing、DuckDuckGo 或百度请求建议，最多显示五条。点建议可搜索，点右边的箭头可填入后继续改。访问过的网站会按域名前缀补全，补出的后缀高亮选中；可以直接覆盖、退格删掉，回车按原网站协议打开。中文仍作为搜索词处理。

**隐私和开关**：「设置 → 在线搜索建议」可以关闭请求；无痕不发建议请求，明确的网址和带凭据的输入也不发。请求不带浏览器 Cookie，不落盘、不记录搜索词，旧请求取消后不会把旧结果盖到新输入上。

**这次怎么验证**：相关编译、地址判断和补全的单元测试，以及模拟器上的地址栏单类测试通过。设备测试用本地 HTTP 服务检查建议处理、填入、取消、开关和无痕；真实搜索服务在手机网络上的可达性还需实机试用。本批没有跑完整常规回归、没有生成 ARM64 发布包，也没有升版本号。

**下一步**：按第一组顺序做网站图标，随后是六个主题色、无痕常驻通知和可跳过的默认浏览器引导。

## 2026-11-03 · 网站图标

**这批做了什么**：接入浏览引擎的网站图标识别和解码。快捷方式、历史、书签和标签页优先显示真实图标；没有图标或获取失败时保留首字母色块。快捷方式继续保留圆形底，标签页顶栏使用小图标。

**缓存和隐私**：普通页面学到的图标只保存在本次进程的内存里，图片缓存最多 8 MB，不新增磁盘图标缓存；重启后会重新获取。历史和快捷方式优先复用已识别的图标，没有记录时尝试该网站自己的 favicon 地址，不把网址交给第三方图标查询服务。请求不带浏览器 Cookie；无痕图标不进入普通页的图片和地址缓存。

**这次怎么验证**：编译、两项图标地址单元测试和模拟器上的两项图标专用测试通过。设备测试用本地网页确认引擎读取页面声明的图标、历史列表实际显示该图片、重复读取不再下载，以及无痕与普通页缓存隔离和缺失图标回退。尚无真手机，真实网站的兼容性仍需手机试用。本批没有跑完整常规回归、没有生成 ARM64 发布包，也没有升版本号。

**下一步**：六个主题色预设，随后补无痕常驻通知和可跳过的默认浏览器引导。缓存区段工作继续冻结。

## 2026-11-03 · 六个主题色

**App 里能看到什么**：「设置 → 外观 → 主题色」新增林檎红、叶绿、藏青、青、紫、石墨六个选项和颜色预览。点选立即改变按钮、开关、链接等主色，纸色背景继续保留；深色模式使用配套的浅主色，无痕页保留深色背景并使用所选颜色的深色配套色。

**设置会怎样保存**：默认仍是林檎红，旧版本没有该设置时自动使用默认色。开启动态取色后使用壁纸色，并暂时禁用预设选择；关闭后恢复之前保存的颜色。Android 12 以下不能开启动态取色，仍可选择六个预设。

**这次怎么验证**：编译、五项相关单元测试和模拟器上的两项主题专用测试通过。检查了六色实际生效、深色色调和按钮文字对比度、动态取色切换、界面重建后保留选择，以及无痕深色切换；也看过实际弹窗，六个选项完整可见。本批没有跑完整常规回归、没有打 ARM64 发布包、没有升版本号，仍未做真手机试用。

**下一步**：补上关闭无痕标签的常驻通知，再做可跳过的默认浏览器首次引导。缓存区段工作继续冻结。
