# 播放器双指缩放 P22

在原生播放器的画面区域，双指捏合可在 1.0–3.0 倍之间缩放，双指移动可平移已超出视口的画面。画面未铺满的轴保持居中，画面边缘不会被拖离该轴的视口。松手时缩放接近「适应」或「填充裁剪」会吸附到相应档位。主动切换显示比例会结束自定义裁剪。

缩放和平移仅调整画面显示，播放控件和字幕仍按正常位置绘制。普通输出与超分输出共用变换，不通过更换解码器或重建着色器处理捏合。旋转后按新视口重新限制平移，画中画使用原比例档，返回播放器时自定义缩放仍可用。

API 35 x86_64 SwiftShader 模拟器 `player-zoom-device-03` 通过 3/3，JUnit 23.074 秒。测试发送真实双指事件，检查最大 3 倍、横纵平移、两个比例档吸附、画面像素实际变化、横竖屏切换及进入画中画时撤下自定义变换。暂停的超分画面仍可放大且不重建渲染器。原有横屏、竖屏和回到全屏的用例也通过。

同包 `player-zoom-single-touch-01` 通过 2/2，JUnit 33.155 秒。原有网页交接的起始位置、单指长按倍速、松手恢复、双击跳转和画中画均通过。
