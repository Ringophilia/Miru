# 「⋮」菜单动效

按 §7.2 和 §7.3，浏览器工具栏和标签切换器都以实际按钮的布局位置打开菜单。顶栏下方有空间时贴着按钮下沿，底栏下方放不下时贴着按钮上沿。菜单整体围绕右上角从 0.85 倍放大并淡入，使用 200 毫秒强调减速。关闭用 100 毫秒强调加速。系统关闭动画时，保留 150 毫秒淡入淡出。菜单项共享同一个过渡。

## 验证

- 固定构建 `overflow-menu-motion-build-05` 通过，774 项源码输入一致。Lint 有 29 项警告、0 项错误。设计和标签模块共 8 项 JVM 测试通过，覆盖顶栏、底栏边缘、横向对齐和空间不足时的位置。
- API 35 x86_64 模拟器重启后，`overflow-menu-motion-device-08` 的 4 项专项全部通过。逐帧比较了缩放原点、两行菜单项间距、退出以及减少动画的几何稳定性。实际浏览器菜单覆盖顶栏、底栏、返回关闭和新建标签。标签切换器菜单覆盖锚点、返回后保留切换器、普通组可关闭全部和空无痕组禁用该操作。
- 早期验证找到了底栏弹窗与按钮之间的间隔，原因是位置计算也对能直接贴合的弹窗留了额外边距。修复后在 `overflow-menu-motion-device-06` 复核了顶栏和底栏贴合、返回关闭，以及用菜单新建一个标签。整体缩放和减少动画两项同轮通过。
- 保留了 ADB 重连失败和 Android 结束启动超时进程的记录。`overflow-menu-motion-device-06` 还记录到 Gecko 网站权限迁移首次失败，重新打开浏览界面后引擎启动。菜单专项允许在报告启动错误时重建一次 Activity，再进入菜单用例。引擎冷启动问题仍待修复。
- 构建和设备日志在 `artifacts/m3-cached-ranges/overflow-menu-motion-*/`，JVM 报告在 `artifacts/overflow-menu-motion/`。APK 大小及 SHA-256 已核对，临时 APK 副本和测试用户已移除。真机和高刷新率表现仍待核对。
