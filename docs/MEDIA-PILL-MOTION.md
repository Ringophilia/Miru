# 地址栏视频胶囊动效

按 §5.3、§5.8 和 §7.3，胶囊显示当前页识别到的可播放视频数量，其中包括识别为可播放的 HLS 和 DASH。入口出现时用弹簧从零宽展开，播放箭头从 0.6 倍放大到正常尺寸，地址栏的域名区域随宽度变化平滑让位。淡入使用 250 毫秒时长，数字与盾牌共享滚动和减少动画下的交叉淡入淡出。读屏语义发布当前数量。

没有可播放视频时，胶囊收起。切换标签或文档时清理上一页的动画状态，当前页的数字跟随网页媒体识别结果。关闭系统动画时直接使用最终宽度，保留透明度过渡。点击胶囊沿用原视频列表和播放入口。

## 验证

- 固定构建 `media-pill-motion-build-02` 通过，763 项源码输入无漂移。设计模块 3 项、媒体识别模块 15 项 JVM 测试通过。工具栏模块无独立 JVM 用例。
- API 35 x86_64 模拟器 `media-pill-motion-device-02` 通过 6 项。受控帧时钟验证胶囊中间宽度、地址栏让位、箭头放大、读数滚动、收起和减少动画时固定宽度；同轮通过共享计数的两项盾牌回归。
- 实际 Gecko 页面加载一个视频后，按本地测试信号追加第二个视频。胶囊依次显示 1 和 2，并打开真实视频列表。用系统返回键关闭面板后，切到新标签页时胶囊消失，切回时恢复为 2。原有实际 HLS 探测及面板显示尺寸的用例同轮通过。
- 首轮在箭头仍被窄胶囊裁剪时取样，另一个断言因直接调用 Activity 返回分发而关闭了标签。调整取样时机及返回输入后整体复测通过，原记录保留。APK 安装包大小、SHA-256、临时拉取文件及测试用户清理均已核对。证据在 `artifacts/m3-cached-ranges/media-pill-motion-*/` 和 `artifacts/media-pill-motion/`。真机、高刷新率和实际读屏仍待验证。
