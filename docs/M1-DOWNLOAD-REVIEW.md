# M1 下载正确性复核

日期：2026-10-22。复核范围为下载分段续传、进程恢复元数据、取消与文件发布的代码路径。

发现并修复两处问题：

- 弱 ETag 允许字节不同的响应保持同一个标记，原实现可能复用旧分段；现在 `DownloadLogic.canResume` 要求强 ETag 或 Last-Modified。弱 ETag 存在时也会比较 Last-Modified 的变化。已有 JVM 测试补充了弱标记、缺失标记和日期变化的回归断言。
- 发布大文件时，原来的同步复制不能响应取消，可能在文件已公开后取消数据库登记。现在 SAF / MediaStore 复制每 64 KiB 检查取消，公开前再次检查；取消或复制失败会删除新建输出。发布成功后的 URI 登记与临时段清理由不可取消的短提交段完成。

本次复核未运行 Gradle 或操作设备。上述修正的最终编译和应用级下载集成测试结果，由根集成步骤记入 [M1-VALIDATION.md](M1-VALIDATION.md)。500 MB 进程终止续传与真实设备存储验收仍需执行。
