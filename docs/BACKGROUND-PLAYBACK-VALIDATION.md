# 后台播放 P18 首批验证

后台播放默认关闭。普通视频打开该设置后，播放器在前台把现有会话接入 Media3 播放服务，由系统发布媒体通知。播放器进入后台时关闭视频轨道并脱离画面输出，保留现有音轨、播放进度与会话。回前台恢复视频轨道，显式关闭播放器时释放会话和服务。后台播放与自动画中画同时设置时，离开应用走纯音频，手动画中画仍可用。打开字幕文件选择器期间沿用原暂停恢复行为。系统不允许启动媒体前台服务时暂停会话。无痕播放保持原有暂停与手动画中画范围。

系统媒体会话的返回动作只携带播放器入口，不携带网址、标题、请求头或恢复凭据。参考已锁定的 Media3 会话服务接口。[Android 后台播放文档](https://developer.android.com/media/media3/session/background-playback)
