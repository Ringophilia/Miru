These files contain locally generated FFmpeg testsrc2 images and a 440 Hz sine wave,
44 seconds at 320×180, H.264/AAC. They contain no third-party film, music or artwork.
The MP4 and its HLS stream-copy are Android instrumentation fixtures only and are not
packaged in the release application. FFmpeg is a development tool, not an app dependency.

Generation commands and device test coverage are recorded in docs/M2-VALIDATION.md.
